## O que é

PRISMA (*Preferred Reporting Items for Systematic reviews and Meta-Analyses*) é a diretriz de **relato** de revisões sistemáticas: diz o que o manuscrito precisa informar para que o leitor entenda e avalie a revisão. Não é um instrumento de qualidade nem um método de conduzir a revisão. A versão 2020 (Page et al., 2021) substituiu a de 2009 e tem três peças:

1. **Checklist de 27 itens** (alguns com subitens; 42 no total) para o manuscrito.
2. **Checklist para resumos** (PRISMA 2020 for Abstracts), com 12 itens.
3. **Fluxograma** do processo de seleção, em versões para revisões novas e para atualizações, com ou sem "outros métodos" de busca.

Extensões: PRISMA-P (protocolos), PRISMA-ScR (revisões de escopo), PRISMA-S (busca), PRISMA-NMA (metanálise em rede), entre outras.

## Fluxograma (versão revisões novas, bases e registros)

```
IDENTIFICAÇÃO
  Registros identificados em:              Registros removidos antes da triagem:
    Bases de dados (n = )                    Duplicatas (n = )
    Registros/cadastros (n = )               Marcados como inelegíveis por automação (n = )
                                             Removidos por outros motivos (n = )
TRIAGEM
  Registros triados (n = )            →    Registros excluídos (n = )
  Relatórios buscados (n = )          →    Relatórios não obtidos (n = )
  Relatórios avaliados para
  elegibilidade (n = )                →    Relatórios excluídos:
                                             Motivo 1 (n = )
                                             Motivo 2 (n = ) ...
INCLUÍDOS
  Estudos incluídos na revisão (n = )
  Relatórios dos estudos incluídos (n = )
```

A versão com **outros métodos** acrescenta uma coluna paralela para registros de sites, organizações, busca por citação etc., com as mesmas etapas de busca de relatórios, não obtidos, avaliados e excluídos por motivo.

**Estudo × relatório:** um estudo pode ter vários relatórios (artigo principal, artigo de seguimento, registro de ensaio). O PRISMA 2020 conta os dois separadamente.

## Checklist (27 itens)

| Seção | Nº | Item | Resumo do que relatar |
|---|---|---|---|
| Título | 1 | Título | Identificar o relato como revisão sistemática |
| Resumo | 2 | Resumo | Ver PRISMA 2020 for Abstracts |
| Introdução | 3 | Justificativa | Justificativa da revisão no contexto do conhecimento existente |
| | 4 | Objetivos | Objetivo(s) ou pergunta(s) explícitos |
| Métodos | 5 | Critérios de elegibilidade | Critérios de inclusão e exclusão e como os estudos foram agrupados para a síntese |
| | 6 | Fontes de informação | Bases, registros, sites, organizações, listas de referências consultados, com data da última busca |
| | 7 | Estratégia de busca | Estratégia completa de todas as bases, com filtros e limites |
| | 8 | Processo de seleção | Como se decidiu a inclusão: quantos revisores, independência, ferramentas de automação |
| | 9 | Processo de coleta de dados | Como os dados foram coletados: quantos revisores, independência, confirmação com autores, automação |
| | 10a | Itens de dados: desfechos | Desfechos buscados e se todos os resultados compatíveis foram coletados |
| | 10b | Itens de dados: outras variáveis | Demais variáveis (participantes, intervenção, financiamento) e suposições sobre dados ausentes |
| | 11 | Avaliação do risco de viés | Instrumento usado, quantos revisores, independência, automação |
| | 12 | Medidas de efeito | Medida de efeito por desfecho (ex.: razão de risco, diferença de médias) |
| | 13a | Métodos de síntese: elegibilidade | Como se decidiu quais estudos entram em cada síntese |
| | 13b | Métodos de síntese: preparo | Preparo dos dados (ex.: conversões, dados ausentes) |
| | 13c | Métodos de síntese: tabulação | Métodos para tabular ou mostrar resultados |
| | 13d | Métodos de síntese: síntese | Métodos de síntese, modelo, heterogeneidade, software |
| | 13e | Métodos de síntese: heterogeneidade | Métodos para explorar causas de heterogeneidade |
| | 13f | Métodos de síntese: sensibilidade | Análises de sensibilidade |
| | 14 | Avaliação de viés de relato | Métodos para avaliar viés por resultados ausentes (viés de publicação) |
| | 15 | Avaliação da certeza | Métodos para avaliar a certeza da evidência (ex.: GRADE) |
| Resultados | 16a | Seleção dos estudos | Resultado da busca e seleção, de preferência com fluxograma |
| | 16b | Estudos excluídos | Estudos que pareciam elegíveis mas foram excluídos, com motivo |
| | 17 | Características dos estudos | Citar cada estudo incluído e apresentar suas características |
| | 18 | Risco de viés nos estudos | Avaliação de risco de viés de cada estudo |
| | 19 | Resultados de estudos individuais | Para cada estudo: estatísticas por grupo e estimativa de efeito com precisão |
| | 20a | Resultados das sínteses: características | Resumo das características e do risco de viés dos estudos em cada síntese |
| | 20b | Resultados das sínteses: estatísticos | Resultados de cada síntese (estimativa, intervalo, heterogeneidade) |
| | 20c | Resultados das sínteses: heterogeneidade | Resultados das investigações de heterogeneidade |
| | 20d | Resultados das sínteses: sensibilidade | Resultados das análises de sensibilidade |
| | 21 | Vieses de relato | Avaliação do risco de viés por resultados ausentes |
| | 22 | Certeza da evidência | Certeza (ou confiança) da evidência por desfecho |
| Discussão | 23a | Interpretação | Interpretação geral no contexto de outras evidências |
| | 23b | Limitações da evidência | Limitações da evidência incluída |

| | 23d | Implicações | Implicações para prática, política e pesquisa futura |

| | 24c | Alterações | Alterações em relação ao registro ou protocolo |
| | 25 | Apoio | Fontes de financiamento e papel dos financiadores |

| | 27 | Disponibilidade de dados | O que está disponível publicamente: formulários, dados extraídos, código, outros materiais |
